# Quiet pane — 승인 전 시안

2026-09-28. 사용자 피드백: 정보는 이해되지만 순수 UI가 좋지 않음.
범위: AP-16/ui의 시각적 구성. 제품 상태·세션 상태·검증 의미는 유지한다.
프로젝트의 Codex-only 지침에 따라 외부 모델 위임 없이 Codex가 기존 화면을 조사했다.

## 관측

실제 w6G:p4는 폭 236칸, pane 높이 7칸이며 표시 내용은 5줄이다.
오른쪽 끝의 수치와 왼쪽 목표가 멀리 떨어져 있고, 진행 배경의 강한 갈색이
문자 중간에서 끊어진다. 본문·보조 정보의 명도 차이가 작다.

## 프리셋

- 기존 전체 면적 진행 배경을 유지하되 track #141B22, fill #182A32로 낮춘다.
  진행량의 위치는 그대로다. 상태 색은 배경 대신 상태 글자에 쓴다.
- 목표와 체크 수치는 한 그룹으로 왼쪽에 배치한다. 화면 끝 정렬을 없앤다.
- 기본 5줄 순서: 목표/체크 수치, 현재 계획, 상태, 마지막 완료 또는 다음 작업, 출처.
- 목표/상태: #EEF4F5, 보조 정보: #A8B6C2, 출처: #7D919F.
  paused/blocked 상태 강조: #E7B66D. 상태는 반드시 글자로도 표현한다.
- 왼쪽 여백 2칸. 주요 내용은 최대 110칸에서 읽히게 하고 배경만 pane 전체에 펼친다.
- 실제 터미널 폰트를 유지한다. 시안의 폰트는 미리보기용이다.
- 짧은 창은 핵심 정보 우선, 큰 창은 기존 목록·조건·근거·이력 자동 노출을 유지한다.
- 깜박임/모션/필수 단축키는 추가하지 않는다. Motion: N/A.

위험: 낮춘 진행 배경의 경계가 약해진다. 수치로도 체크율을 명시하고
실제 ANSI 렌더·작은/넓은 창에서 읽기 가능 여부를 확인한다.
